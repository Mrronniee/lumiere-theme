# LUMIERE

A free Shopify theme by **[Kiosk](https://kioskthemes.com)** — a boutique
storefront for fashion and lifestyle brands. Built on Online Store 2.0, with
no third-party apps required.

### ▶ [Browse the live demo](https://kioskthemes.com/demo/lumiere/)

A full, navigable storefront — home, collection, product, cart, journal and
contact — running this exact theme. No signup, nothing to install.

## What's inside

| Area | What you get |
| --- | --- |
| Storefront | full-width hero, featured collection, image with text, rich text, newsletter |
| Shopping | product page with variant picker and size guide, collection with filters and sorting, cart drawer, quick view |
| Content | journal (blog), about and contact pages, predictive search |
| Extras | wishlist, currency and country selector, sticky add-to-cart on mobile |

Every section is standalone: add, reorder or remove it from the theme editor
without touching code.

## Install

1. Download the latest release, or clone this repository and zip its contents.
2. In your Shopify admin: **Online Store → Themes → Add theme → Upload zip file**.
3. Preview it, then **Publish** when you are happy.

The full walkthrough, with the settings worth changing first, is at
[kioskthemes.com/docs/lumiere](https://kioskthemes.com/docs/lumiere/).

## What this theme does not do

Stated plainly, so you can judge before installing:

- It does not replace apps for subscriptions, loyalty or advanced bundling.
- The wishlist is stored in the browser, not on a customer account.
- Translations cover English and French; other languages need your own files.
