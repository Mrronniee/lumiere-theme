WHAT'S IN THIS DOWNLOAD
  lumiere-theme.zip  The theme. Upload THIS file to Shopify.
  INSTALLATION.md    Ten-minute setup guide - start here.
  LICENSE.md         What you may and may not do with LUMIERE.
  CHANGELOG.md       What's in this release.

QUICK START
  Shopify admin -> Online Store -> Themes
  Add theme -> Upload zip file -> pick lumiere-theme.zip
  Your live theme is not touched. Preview first, publish when ready.

AFTER INSTALLING
  Create a page with the handle "contact" and assign the page.contact template.
  Create a page with the handle "wishlist" and assign the page.wishlist template.
  Both are covered in INSTALLATION.md.
